Rules every step follows

Alderman never reaches treasury actions

The shared ui_act admits the Alderman remotely through alderman_has_access(), even when the machine is locked. Treasury actions go through their own gate, checked before anything else.

Ship only the open tab's data

ui_data already builds the market view on every tick. Treasury payloads are built only for the tab the viewer has open, using the per-ckey pattern of ledger_view.

Validation stays on the server

Every input() becomes an inline control, but the whole-number check, fine cap, wage floor clamp and self-fine refusal stay in DM.

Mobs by ref, re-verified

Rows send REF(mob). The server locates it and confirms it is still in SStreasury.bank_accounts (or still a debtor) before acting.

Keep logs and messages

Every log_game, say() and to_chat to the subject from the old Topic branch moves with the action.

Delete as you go

Each step removes its legacy tab branch and hrefs in the same commit, so the diff shows old and new side by side.
